# Glossary (the human owns this; the AI uses these words exactly)

| Term | Meaning |
|---|---|
| Showcase | The visual, motion-heavy pages (home and case studies). |
| Case study | One MDX page describing a single project. |
| Post | One MDX blog page. |
| Static export | Next.js builds plain HTML/CSS/JS into `out/`, with no server needed. |
| basePath | URL prefix needed when the site lives at `user.github.io/repo`. |
| Frontmatter | The block of fields at the top of an MDX file (title, date, tags). |
| Velite | The tool that turns MDX files into typed data at build time. |
| Wrapper | A small component in `animations/` that adds motion to its children. |
| Reduced motion | An OS setting asking sites to avoid animation. |
