This is a brand-new project, so there is no approved design yet. Do not write code.
1. Read `docs/requirements.md` and ask the human about mood, colours, fonts, references they like, and the "Open questions" listed there.
2. Use the `designer` agent to propose 2-3 directions in plain language, each with a reason and a note on how motion would work and fall back under reduced motion.
3. After the human picks one, save it to `docs/design.md` and list any spec or requirement gaps as ADR drafts in `.claude/logs/adr-drafts/`.
Stop and wait for approval at each step.
