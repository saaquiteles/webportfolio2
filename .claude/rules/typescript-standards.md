# TypeScript and front-end standards (summary)
The numbered originals in `docs/standards.md` win. Key ones:
- `TS-01` strict, no `any`. `TS-02` shared types in `src/lib/types.ts`.
- `ST-02` only `animations/` imports `framer-motion`. `ST-05` theme tokens only.
- `A11Y-01..05` landmarks, keyboard, reduced motion, alt text, contrast.
- `CT-01..03` content schema, drafts, images. `SE-01..02` static export limits.
Cite rule IDs in reviews and learning notes.
