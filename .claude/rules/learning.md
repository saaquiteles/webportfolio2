# Learning notes
One note per task in `.claude/logs/learning/`, named `YYYY-MM-DD-<task>.md`, from `TEMPLATE.md`.
- **Draft** after the tests pass. **Final** after review (add "What the review changed", set `Status: Final`).
- Sections: what was built, why this way, key terms, follow the flow through the files, what the tests prove, what the review changed, 3 likely questions.
- Define every term in plain words with an everyday example. Short at Level 1.
