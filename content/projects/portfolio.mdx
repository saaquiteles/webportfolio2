This site is the project. It is a static Next.js site, built so it can be hosted on GitHub Pages. Every project is typed data plus one MDX file, so adding a project needs no code change.

## Built with

Next.js, TypeScript, Tailwind CSS, Velite with MDX, and Vitest.

[Source code on GitHub](https://github.com/saaquiteles/webportfolio2)

## How it was built

Every task was built test first with Claude Code. An automated check runs the type check, lint, tests and the static build, a second agent reviews each change, and each task ends with a learning note.

## Credits

The agentic workflow was simplified with ideas from [Matt Pocock's skills](https://github.com/mattpocock/skills).
