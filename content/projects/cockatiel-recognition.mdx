## The paper

Recognition of Feather and Color Mutation on Cockatiels via Raspberry Pi Using OpenCV and SqueezeNet, published in Advances in Transdisciplinary Engineering (IOS Press), 2025.

[Read the published paper](https://ebooks.iospress.nl/doi/10.3233/ATDE251126)

## What it does

A real-time image classification system for cockatiel feather and color mutations, running on a Raspberry Pi 4B. It detects the bird with OpenCV's Haar cascade classifier and classifies five mutations (Cinnamon, Pied, Pearl, Lutino and Whiteface) with a trained SqueezeNet model.

## Highlights

- Achieved 91.17% accuracy.
- Ensembled approach with Haar Cascade and SqueezeNet for robust detection and classification.
- Optimized embedded system performance for real-time inference on resource-constrained hardware.

## Tech
